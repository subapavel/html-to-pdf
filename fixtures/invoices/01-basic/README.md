# 01 — basic

Single-page Czech invoice. The smallest thing that must be pixel-close to Chrome.

Exercises:
- `flex` header with `justify-between`, `items-start`
- `grid grid-cols-2 gap-8` supplier/customer block
- plain `<table>` with `border-b` rows (no `border-collapse` yet — see 03)
- `tabular-nums`, `text-right` number alignment
- Czech diacritics (ěščřžýáíéůú) in Inter, `uppercase` + `tracking-wider`
- `@page { size: A4; margin: 15mm }`
- `font-mono` span inside `font-sans` paragraph (inline font switch)
